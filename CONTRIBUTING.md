# Contributing to Mac iPhone Mirroring for EU Countries

Contributions are warmly welcomed. This repository is an early working draft, and help with Swift, AppKit, SwiftUI, ReplayKit, VideoToolbox, networking, XCTest, accessibility, performance, or security would be especially valuable.

## Before opening a pull request

1. Do not commit certificates, provisioning profiles, Apple team IDs, device IDs, private IP addresses, or other personal data.
2. Keep this repository focused on the iPhone-to-Mac experience; Vision Pro implementations belong in their respective repositories.
3. Explain which Mac/iPhone models, OS versions, Xcode version, and connection you tested.
4. Preserve the attribution in `NOTICE` and document any third-party code or assets.
5. Do not imply feature parity with Apple's private iPhone Mirroring implementation.

Useful areas include easier device configuration, authenticated transport, lower input latency, audio, rotation, reconnect behavior, accessibility, performance measurements, and documentation.
