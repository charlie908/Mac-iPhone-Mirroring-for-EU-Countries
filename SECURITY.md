# Security policy

## Experimental status

Mac iPhone Mirroring for EU Countries is a development prototype. Its local video and control protocol has no application-level authentication or encryption. Use it only with a trusted Mac, iPhone, and network. Never expose its services to the public internet.

## Sensitive material

Never submit Apple certificates, provisioning profiles, signing keys, Apple team identifiers, device identifiers, account credentials, private IP addresses, captured screens, or logs containing personal data.

## Reporting a vulnerability

Please use GitHub's private security-advisory feature for vulnerabilities that could expose data or enable unauthorized control. Do not publish exploitation details in a public issue before a fix is available.

No response time or security-support period is guaranteed for this experimental project.
